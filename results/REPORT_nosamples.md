# Прогон без примеров строк: условия сближены, разрыв остался

Гипотеза с обоими исходами — `results/HYPOTHESIS_nosamples.md`, коммит
`182f6f6`; флаг закоммичен раньше и как есть — `9fcc483`. Прогон:
`runner/run_questions.py --no-samples`, 14 × 3, слой `metrics.yml`
целиком, модель прежняя. Полный вывод — `selfcheck/nosamples_output.txt`.

## Что сравнялось и что нет

| | самооценка | прогон с флагом |
|---|---|---|
| состав витрины, колонки, число строк | есть | есть |
| `metrics.yml` целиком | есть | есть |
| примеры строк | нет | **нет** ← сравнялось |
| исполнение SQL | нет | **есть** ← осталось |

**Оговорка, которую не заглаживаю.** Условия сравнялись НЕ полностью: SQL
в самооценке не исполняется вовсе. Поэтому согласие по-прежнему **не
устанавливает связи** между самооценкой и поведением — оно лишь посчитано
при более узком разрыве условий. И «факт» здесь — моя разметка по
эталонам из ручек генератора, а не правильность ответа.

## Что из этого следует

**Разрыв держится не на условиях.** Из двух разниц снята одна — большая
по объёму контекста (две строки на каждую из семи таблиц) — и согласие
осталось в прежней полосе. Значит расхождение самооценки с разметкой
происходит не оттого, что агент в самооценке «не видел данных», а оттого,
что двузначная шкала «могу / не могу» не вмещает состояния «посчитать
можно, но одного числа не будет». Это тот же вывод, что и прежде, но
теперь он получен при снятой части возражений, а не вопреки им.

**Что сравнение по-прежнему не даёт.** Связи между самооценкой и
поведением. Для неё нужен третий замер — самооценка после разведки
данными, до ответа; вторая разница условий (исполнение SQL) не снята и
этим прогоном не снимается.

## Чего в выводы не берётся

**Уровень «справился».** 7 из 14 здесь против 9 из 14 (01.09) и 6 из 14
(02.09) — в выводы не идёт. Причины две, и вторая важнее первой:
воспроизводимость отдельной ячейки 61.3%, а эталон стенда взят из ручек
генератора, и верность на нём не утверждается вовсе. Меряется согласие
внутри одного прогона, а не движение уровня между прогонами.

Для полноты записи, без выводов: исходы прогона — верных 26, наивных 4,
мимо 12, уточнил 0; обрывов по `max_tokens` нет; спорных ячеек (сработали
оба набора маркеров) 16.
